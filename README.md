# Task 1 — Responsive Landing Page

A simple responsive landing page created for the Web Development Internship Task 1.

## What I built

- Semantic HTML5 structure with header, navigation, main content and footer
- Responsive hero section with call-to-action links
- CSS Grid and Flexbox for the page layout
- Mobile navigation using a CSS checkbox toggle
- Responsive media queries for tablets and mobile screens
- Hover and focus-friendly interactions without JavaScript
- No paid tools or frameworks required

## Files

- `index.html` — page structure and content
- `style.css` — layout, typography, responsive rules and visual styling

## How to run

1. Open the folder in VS Code.
2. Open `index.html` with Live Server, or open the file directly in Chrome.
3. Resize the browser window to check the responsive layout.

## Key concepts demonstrated

HTML5, CSS3, semantic elements, Flexbox, Grid, media queries and responsive design.
